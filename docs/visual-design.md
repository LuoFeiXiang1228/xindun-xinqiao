# 视觉设计与第三方插画

## 视觉设计

采用奶油白、鼠尾草绿和暖杏色；用留白和统一文字层级区分介绍、操作和补充说明。首屏只保留项目主张与两个体验入口。

- 心盾：四项核对与提示分列；事实、暂时判断、修订结果形成三栏对照。
- 心桥：五节点连线区分完成、当前和后续步骤；无需转介分支使用独立的跳过标记。文字与符号补充颜色。
- 切换角色：可以按指引直接切换到下一位负责人，也可手动选择角色；这些是交互讲解，不是服务端权限。
- 固定示例、完整记录、角色边界和反馈表默认折叠，避免主流程与说明竞争注意力。
