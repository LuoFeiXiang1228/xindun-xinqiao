# 可以直接参与的改进任务

作者：罗费翔（LuoFeiXiang）。协作以明确的小任务开始；不需要提供真实学生或学校数据。

| 编号 | 任务 | 建议交付物 | 验收方式 |
| --- | --- | --- | --- |
| UX-01 | 手机与键盘体验 | 问题截图、操作步骤、设备宽度 | 无横向溢出，全部动作能通过键盘完成；问题可复现 |
| FLOW-01 | 评阅协作交接 | 基于虚构案例的角色、责任与缺失步骤意见 | 指明在哪个状态由谁做什么，说明是否会造成遗漏 |
| COPY-01 | 检查提示是否容易误解 | 原文、误解原因、建议文案 | 不把规则当诊断，不把模拟提交当真实发送 |
| TEST-01 | 状态机拒绝路径 | 新增测试与问题解释 | 覆盖新的实际失败路径，不只复述已有实现 |
| ENG-01 | 服务端最小闭环设计 | 接口草案、资源授权规则、拒绝案例 | 覆盖跨班、撤销授权、重复操作和任务归属变化 |

认领前先用 Issue 说明任务编号和预计交付物，避免重复工作。可先讨论设计，再提交小范围 PR。代码贡献采用 MIT，文档贡献采用 CC BY 4.0，保留已有署名。

首轮体验记录按 [可用性验证说明](usability.md)填写。真实后端和机构试用仍属于后续阶段；当前不招募真实健康记录，不承诺部署、报酬或专业服务。
